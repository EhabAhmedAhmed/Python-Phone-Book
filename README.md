# Python Phone Book

## About the Project
A simple phone book application built with Python.

## Features
- Search for a contact by phone number.
- Search for a phone number by name.
- Add new contacts.
- Validate phone numbers to ensure they contain exactly 10 digits.

## Concepts Used
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Input Validation

## How to Run
Run the following command:

```bash
python phone_book.py
```

## Project Type
Beginner Python Practice Project.
